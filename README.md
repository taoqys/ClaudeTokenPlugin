# Claude Token Monitor - TrafficMonitor Plugin

Displays Claude Code daily token usage on the Windows taskbar via [TrafficMonitor](https://github.com/zhongyang219/TrafficMonitor).

## Display Items

| Item | Label | Example |
|------|-------|---------|
| Total Tokens | `Claude` | `2.1M` |
| Input Tokens | `In` | `229K` |
| Output Tokens | `Out` | `6K` |
| Cache Read | `Cache` | `1.9M` |

## Installation

1. Download `ClaudeTokenPlugin.dll` from [Actions](../../actions) artifacts
2. Place it in TrafficMonitor's `plugins/` directory (next to `TrafficMonitor.exe`)
3. Restart TrafficMonitor
4. Right-click TrafficMonitor → select display items → enable the ones you want

## Prerequisites

The plugin reads `~/.claude/.token-cache.json`, which is generated by `claude-token-monitor.py`.

```bash
python claude-token-monitor.py
```

## Building from Source

```bash
cmake -B build -G "NMake Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

Output: `build/bin/ClaudeTokenPlugin.dll`
